# Профиль far2l-2.6 (far2l 2.6.5 – 2.7.x)

Проверено на 2.6.5-beta (Debian 12, `bookworm-backports`). Сборки, которые называют себя
«2.6.5-beta», бывают с разных коммитов от 30.03.2025 до 26.10.2025, поэтому установщик пишет
имена цветов всех известных версий сразу: лишние far2l игнорирует.

Файл `settings/farcolors.ini` появился в far2l 27.12.2024, внутри разработки 2.6.4. Более старые
сборки хранят цвета иначе. Поэтому профиль требует, чтобы в бинарнике far2l была строка
`settings/farcolors.ini` (`requires` в `profile.json`); без неё установщик останавливается с кодом 3.

## Чем 2.6 отличается от 2.8 (важно для темы)

| Что | far2l 2.6 | far2l 2.8 |
|---|---|---|
| Темы | нет; цвета только в `settings/farcolors.ini` | `settings/themes/<имя>/farcolors.ini` + `[Colors] CurrentTheme` |
| Цвет итоговой строки панели | `Panel.Info.Tota` (опечатка в самом far2l) | `Panel.Info.Total` |
| Цвет, которого нет в файле | белый на **красном** (`B_RED \| F_WHITE`) | штатный синий |
| Сохранение цветов | при Shift+F9, при выходе с AutoSaveSetup=1, при первом запуске с русской локалью | только если цвета меняли в настройках |
| Коррекция контраста | нет | есть в сборках новее 2.8.0 — поэтому в теме уже записаны скорректированные значения |
| `far2l --version` | **нет такого ключа** — команда запускает сам far2l | печатает версию |
| Версия | первая строка `far2l -h` | то же |
| Colorer: не загрузился `UserHrdPath` | показывает ошибку и **выключает Colorer насовсем** (`Enabled=0`) | пишет в журнал и продолжает |
| Colorer: не нашлась или сломана сама схема | берёт схему `default` (синий редактор) | то же |

Формат значений цвета, `palette.ini`, группы раскраски файлов, ключи Colorer и правила поиска
каталога настроек в 2.6 такие же, как в 2.8.

## Откат на 2.6

Переключателя тем в 2.6 нет. Надёжный способ — `python3 install.py --restore <копия>`.
Пункт «Параметры → Цвета → Установить стандартные цвета (RGB)» строит цвета из `palette.ini`,
то есть из палитры темы, поэтому классического синего вида без отката палитры он не даст.

## Источник имён цветов

`keys.txt` — список `ColorsInit` из `far2l/src/console/farcolors.cpp` тега `v_2.6.5` (147 имён).
