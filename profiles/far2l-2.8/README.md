# Профиль far2l-2.8 (far2l 2.8.0 и новее)

Проверено на 2.8.0-beta (сборка `git1b5e155`, Fedora 44, COPR `polter/far2l`).
Для версий новее 2.8 используется этот же профиль, пока не появится отдельный.

## Как здесь устроены цвета

- Тема: `settings/themes/GNOME Graphite/farcolors.ini`, выбирается ключом
  `[Colors] CurrentTheme=GNOME Graphite` (и `CurrentThemeIsSystemWide=0`) в `settings/colors.ini`.
- Тему видно и можно сменить в far2l: F9 → Параметры → Цвета (раздел «Темы пользователя»).
- Если цвета поменять в настройках far2l, он сохранит их в ту же пользовательскую тему.
- Сборки новее 2.8.0 сами осветляют малоконтрастный текст (EnforceColorCorrection).
  В теме уже записаны значения после такой коррекции, поэтому вид не меняется.
- `settings/farcolors.ini` установщик в этой версии не трогает: это «Пользовательские цвета»,
  к которым можно вернуться из меню.

## Источник имён цветов

`keys.txt` — список `ColorsInit` из `far2l/src/console/farcolors.cpp` коммита `1b5e155` (160 имён).
По сравнению с 2.6.5 добавлены 13 имён, `Panel.Info.Tota` переименован в `Panel.Info.Total`.
