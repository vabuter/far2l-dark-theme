# Инструкция для ИИ-агента: установка темы far2l «GNOME Graphite»

Задача: установить тему из этого репозитория в far2l текущего пользователя. Один установщик
работает на разных версиях far2l и дистрибутивах: версию он определяет сам и берёт правила
из `profiles/`.

Работа считается сделанной, когда:

1. `python3 install.py --verify` печатает `ИТОГ: всё установлено` и завершается с кодом 0;
2. пользователь получил путь к резервной копии и команду отката.

## Правила

- **Не запускайте `far2l --version`.** В far2l 2.6 такого ключа нет: команда запускает сам far2l
  (на рабочем столе откроется окно, агент повиснет, в настройках появятся файлы первого запуска).
  Версию показывают `far2l -h | head -1` и `python3 install.py --detect`.
- Не запускайте far2l без `--tty` и без нужды: на рабочем столе он откроет окно.
- Не запускать через `sudo`. Всё ставится в домашний каталог, системные файлы (`/usr/...`) не трогать.
- Не завершать процессы far2l самостоятельно: в его редакторе могут быть несохранённые файлы.
  Если far2l запущен, попросите пользователя закрыть его (F10) и дождитесь подтверждения.
- Не править цвета вручную в каталоге настроек. Цвета интерфейса и палитра — в `far2l_theme/colors.py`,
  цвета подсветки синтаксиса в редакторе — в `theme/graphite.hrd`.
- Не удалять резервные копии `*-backup-*.tar.gz`.
- Пакеты (far2l, tmux, Pillow и т. п.) ставить только с согласия пользователя.

## 1. Проверить окружение

```bash
python3 install.py --detect
```

Команда ничего не меняет. Она печатает путь к far2l, его версию, выбранный профиль, наличие
графического модуля и каталог настроек. Что проверить:

- `far2l: не найден в PATH` — far2l не установлен. Сообщите пользователю, как его поставить
  (см. `environments/*/README.md`; в Debian 12 сначала нужно подключить `bookworm-backports`).
- Профиль `far2l-2.6` или `far2l-2.8` — всё штатно. Прочитайте `profiles/<профиль>/README.md`.
  Профиль выбирается по версии и проверяется по самому бинарнику far2l (строки
  `settings/farcolors.ini`, `settings/themes/`): у снимков из git один номер версии на месяцы разработки.
- `профиль: нет (… нужна 2.6.5 или новее)` — сборка хранит цвета иначе, тема на неё не встанет;
  установка остановится с кодом 3. Предложите пользователю обновить far2l.
- `профиль: нет (версию far2l определить не удалось)` — far2l не найден или не отвечает на `-h`.
  Установка возможна (цвета пишутся во все места сразу), но сообщите, что версия не проверена.
- Каталог настроек должен совпадать с тем, которым пользуется far2l. Если пользователь запускает
  far2l с `-u ПУТЬ` (полный путь), передавайте `--config-dir ПУТЬ/.config`; с `-u ИМЯ` —
  `--config-dir ~/.config/far2l/custom/ИМЯ`.

Ещё две проверки:

```bash
python3 --version
```

```bash
command -v tmux
```

Нужен Python 3.8+. tmux желателен: без него установщик не сможет сам выполнить первый запуск
far2l, которого ещё ни разу не запускали (см. «Решение проблем»).

## 2. Установить

```bash
python3 install.py
```

Строки вывода: `[ok]` — шаг выполнен, `[!]` — предупреждение (прочитайте и передайте пользователю),
`[-]` — шаг неприменим, `[STOP]` — установка не начата.

Коды выхода: `0` — готово, `2` — запущен far2l, `3` — сборка far2l не поддерживается,
`1` — не удалась резервная копия или другая ошибка (до записи настроек ничего не изменено).

Что делает установщик:

1. резервная копия каталога настроек и пользовательских иконок рядом с каталогом настроек
   (`~/.config/far2l-backup-ГГГГММДД-ЧЧММСС.tar.gz`);
2. если в `settings/colors.ini` нет групп раскраски файлов (far2l ни разу не запускался), запускает
   far2l в tmux в терминальном режиме и выходит из него, чтобы появились штатные настройки;
3. цвета интерфейса: на 2.8+ — тема `settings/themes/GNOME Graphite/farcolors.ini` и
   `[Colors] CurrentTheme`; на 2.6–2.7 — ещё и `settings/farcolors.ini` (тем там нет);
4. `palette.ini`;
5. группы раскраски файлов: имя под курсором того же цвета, что и без курсора; у групп
   от far2l до 2.6.2 убирается синий фон;
6. Colorer: `plugins/colorer/graphite.hrd`, `user-hrd.xml` (схемы пользователя из прежнего
   `UserHrdPath` — файла, каталога или своего прошлого `user-hrd.xml` — сохраняются),
   ключи в `plugins/colorer/config.ini`;
7. иконки в `~/.local/share/icons/hicolor/scalable/apps/` и переопределения `.desktop`
   в `~/.local/share/applications/` для всех найденных ярлыков far2l (только Linux). Если у
   пользователя был свой ярлык, он берётся за основу, и его правки сохраняются. Переопределение,
   сделанное из системного ярлыка, при каждом запуске строится заново (так подхватываются
   обновления far2l), поэтому править его вручную бесполезно — правьте свой ярлык до установки.

В конце установщик печатает строку `откат к виду до темы: python3 install.py --restore …` — это
самая свежая копия без темы, то есть состояние прямо перед установкой темы на чистые настройки.

Установку можно запускать повторно: результат тот же, каждый запуск делает новую резервную копию
(копии повторных запусков уже содержат тему). Если каталог настроек или файлы в нём — ссылки
(dotfiles), установщик пишет в их цели, а копия и откат это учитывают.

Полезные ключи: `--skip-icons`, `--skip-colorer`, `--skip-palette`, `--skip-highlight`
(с теми же ключами запускайте и `--verify`), `--enable-colorer`, `--no-bootstrap`,
`--profile far2l-2.6|far2l-2.8`, `--config-dir DIR`, `--data-home DIR` (вместо `~/.local/share`).
`--force` — только если запущенный far2l точно работает с другим каталогом настроек.

## 3. Проверить

```bash
python3 install.py --verify
```

Все строки должны быть `[ok]`; `[-]` означает «неприменимо», `[!]` — предупреждение, не ошибка.

Визуальная проверка. far2l запускается на копии настроек, настоящие настройки не меняются:

```bash
python3 tools/snapshot.py --out /tmp/far2l-shots
```

Режим выбирается сам: `gui` (графическое окно far2l в Xvfb — так его видит пользователь;
нужны Xvfb, xdotool, ImageMagick и Pillow) или `tty` (tmux). Копия настроек делается без
символьных ссылок, поэтому снимки ничего не пишут в настоящие файлы. Проверить цвета автоматически:

```bash
python3 tools/shotcheck.py --backend gui --dir /tmp/far2l-shots
```

(для режима `tty` — `--backend tty`). Что проверяется (±3 из-за округления):

| Экран | Что должно быть |
|---|---|
| `panels` | фон `#1d1d20` преобладает, есть `#254165` (курсор) и `#1c71d8` (заголовок активной панели) |
| `menu` | есть фон `#36363a` (выпадающее меню) |
| `dialog` | есть фон `#36363a` (диалог создания папки) |
| `warning` | есть фон `#a51d2d` (красное предупреждение) |
| `editor` | фон `#1d1d20`; текст `≈#ffa348` (ключевые слова) — значит, Colorer применил схему `graphite` |

Если вы умеете смотреть изображения, откройте `panels.png` и `editor.png`. Признаки проблем:
синий фон (`#000080`, `#000060`), бирюзовый курсор (`#008080`), красная строка внизу панели
(`#e01b24`). В режиме `tty` старые tmux (3.3a в Debian 12) не отдают стёртые клетки в конце строк;
far2l 2.6 стирает так пустые места редактора. На PNG такие клетки фиолетовые, в сводке —
«не захвачено tmux»: это не ошибка темы.

## 4. Сообщить пользователю

- путь к копии до темы (из строки `[ok] откат к виду до темы: …`);
- откат: `python3 install.py --restore <путь к этой копии>`;
- на far2l 2.8 тему можно сменить в программе: F9 → Параметры → Цвета;
- новая иконка в доке может появиться только после повторного входа в сеанс
  (в X11 достаточно Alt+F2 → `r`).

## Решение проблем

| Симптом | Причина и решение |
|---|---|
| `[STOP] far2l запущен` | Попросите пользователя закрыть far2l (F10) и повторите. Если окна нет, far2l мог остаться в фоне после закрытия терминала: пусть пользователь запустит far2l в терминале (он предложит вернуть фоновый сеанс) и выйдет по F10. |
| `[STOP] …: эта сборка far2l хранит цвета иначе` (код 3) | far2l старше 2.6.5 (или снимок 2.6.4 до декабря 2024). Тема на него не встанет: предложите обновить far2l. |
| `[STOP] резервная копия не создана: …Permission denied…` (код 1) | В каталоге настроек есть файлы, которые пользователь не может прочитать (обычно от `sudo far2l`). Предложите `sudo chown -R $USER <каталог настроек>`; ничего не изменено. |
| `[!] не удалось автоматически создать настройки far2l` | Нет tmux или far2l не в `PATH`. Попросите пользователя один раз запустить far2l и выйти по F10, затем повторите `python3 install.py`. |
| `[!] far2l нельзя запустить с этим каталогом настроек` | `--config-dir` указывает на каталог, которым far2l не пользуется. Подходят: каталог по умолчанию, `ПУТЬ/.config` (`far2l -u ПУТЬ`), `~/.config/far2l/custom/ИМЯ` (`far2l -u ИМЯ`). |
| `--verify`: `раскраска файлов: 0 групп` | То же: far2l ещё не запускался. |
| `[!] нет явного правила для N цветов` | Новая версия far2l добавила цвета. Они подобраны по названию; точные правила добавляются в `FIXED` в `far2l_theme/colors.py`, а имена — в новый профиль. |
| Внизу панели красная строка (2.6) | Цвет `Panel.Info.Tota` отсутствует или равен `B_RED \| F_WHITE`: far2l сохранил настройки (Shift+F9) после загрузки файла без этого цвета, например от старой версии установщика. Закройте far2l и установите заново; `--verify` покажет `Panel.Info.Tota` среди отсутствующих («нет:») или отличающихся цветов. |
| far2l всё ещё синий | far2l был открыт во время установки (или настройки сохранены по Shift+F9). Закройте его и установите заново. |
| `[!] Colorer выключен (Enabled=0)` | Подсветки в редакторе нет. Спросите пользователя и выполните `python3 install.py --enable-colorer`. На 2.6 Colorer выключает себя сам, если не загрузился файл `UserHrdPath` или каталог схем. |
| Редактор синий, остальное тёмное | Colorer не нашёл схему `graphite` и взял `default`. Проверьте `--verify` (строки Colorer). |
| `[!] иконки: .desktop-файлы far2l не найдены` | Не установлен графический модуль (в Debian пакет `far2l-wx`) или far2l собран без ярлыков. Найдите ярлык: `grep -l '^Exec=far2l' /usr/share/applications/*.desktop`; если имя другое — добавьте его в `DESKTOP_ICONS` в `far2l_theme/steps.py`. |
| Иконка не сменилась | Выйти из сеанса и войти снова (в X11: Alt+F2 → `r`). На macOS иконки не ставятся. |

## Ручная установка (если Python недоступен)

`theme/farcolors.ini` содержит имена цветов всех известных версий (лишние far2l игнорирует).
Ниже `CFG` — каталог настроек far2l (обычно `~/.config/far2l`). far2l должен быть закрыт.

1. Резервная копия: `tar czf ~/.config/far2l-backup-manual.tar.gz -C ~/.config far2l`.
2. Цвета: скопировать `theme/farcolors.ini` в `CFG/settings/themes/GNOME Graphite/farcolors.ini`
   и, для far2l 2.6–2.7, ещё в `CFG/settings/farcolors.ini`.
3. В `CFG/settings/colors.ini` в секции `[Colors]` (создать, если нет): `CurrentTheme=GNOME Graphite`
   и `CurrentThemeIsSystemWide=0`.
4. Скопировать `theme/palette.ini` в `CFG/palette.ini`.
5. Раскраска файлов: можно пропустить (имена под курсором будут хуже читаться). Вручную: в каждой
   секции `[Colors/Highlight/GroupN]` файла `CFG/settings/colors.ini`, где младший байт `NormalColor`
   и `CursorColor` не ноль, записать `CursorColorMask=0xfffffffd0f` и `CursorColor` =
   (RGB цвета текста в порядке BGR) << 16 | `0x10f`. RGB — из `NormalColor`, если там есть флаг `0x100`,
   иначе из `theme/palette.ini` `[foreground]` по индексу `NormalColor & 0xF`.
6. Colorer: скопировать `theme/graphite.hrd` в `CFG/plugins/colorer/graphite.hrd`; создать
   `CFG/plugins/colorer/user-hrd.xml` (путь в `link` — абсолютный, спецсимволы XML экранировать):

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <hrd-sets>
     <hrd class="rgb" name="graphite" description="GNOME Graphite">
       <location link="АБСОЛЮТНЫЙ_ПУТЬ_К/graphite.hrd"/>
     </hrd>
   </hrd-sets>
   ```

   В `CFG/plugins/colorer/config.ini`, секция `[Settings]`: `HrdNameTm=graphite`, `HrdName=black`,
   `TrueMod=1`, `UserHrdPath=` абсолютный путь к `user-hrd.xml`. Ошибка в `user-hrd.xml` на far2l 2.6
   выключает Colorer насовсем (`Enabled=0`), ошибка в `graphite.hrd` даёт синий редактор (схема default) —
   проверяйте XML перед записью `config.ini`.
7. Иконки (Linux): `icons/*.svg` скопировать в `~/.local/share/icons/hicolor/scalable/apps/`;
   найденные `far2l.desktop`, `far2ledit.desktop`, `far2l-tty.desktop`, `far2ledit-tty.desktop`
   скопировать из `/usr/share/applications/` в `~/.local/share/applications/` и заменить в них `Icon=`
   на `far2l-graphite` (для `far2l*`) или `far2ledit-graphite` (для `far2ledit*`).

## Как это устроено (для доработок)

- **Профили** (`profiles/<имя>/profile.json`): диапазон версий, пишутся ли цвета в тему
  (`uses_themes`), какие строки должны быть в бинарнике far2l (`requires`), список имён цветов
  этой версии (`keys.txt`). Новая версия far2l с другим поведением — новый каталог профиля;
  общий код менять не нужно, если механизм тот же.
- **Окружения** (`environments/<имя>/`): особенности дистрибутива, `Containerfile` для проверки,
  `expect.json` (какая версия far2l, какой профиль и какой точный пакет должны оказаться в контейнере),
  снимки. Новое окружение — новый каталог с этими файлами и `README.md`; `tools/e2e.py` подхватит его сам.
  Если e2e пишет, что пакет в образе другой, — дистрибутив обновил far2l: перепроверьте окружение
  и обновите `expect.json`, README окружения и `tested` в профиле.
- Значение цвета в `farcolors.ini` far2l читает до `;`:
  `background:#rrggbb foreground:#rrggbb, B_<ИНДЕКС> | F_<ИНДЕКС>`. RGB используется в TrueColor,
  индексы — запасной вариант для `--norgb` и 16-цветных терминалов.
- Файл цветов всегда содержит имена **всех** известных версий (`Panel.Info.Tota` и `Panel.Info.Total`
  одновременно): недостающее имя far2l рисует синим (2.8) или красным (2.6), лишнее — игнорирует.
- Группы раскраски задают только цвет текста (маска `0xfffffffd0f`); индексные цвета рисуются
  через `palette.ini`. Цвет имени под курсором установщик пишет как RGB обычного цвета плюс
  запасной индекс белого: без TrueColor (`--norgb`, а в 2.8 — `TERM=screen*`) курсор синий
  (`B_BLUE`), имя на нём белое. Запасные индексы всех цветов подбираются по палитре терминала
  с контрастом не ниже 3:1 (`index_pair` в `colors.py`). В терминальном режиме far2l отдаёт терминалу одну палитру: цвета 0–7 из
  `[background]`, 8–15 из `[foreground]`, поэтому `[background]` 1–7 подобраны читаемыми и как текст.
- Colorer при `TrueMod=1` и TrueColor берёт RGB-схему `HrdNameTm`; пользовательские схемы
  подключаются через `UserHrdPath` (файл `<hrd-sets>`, ссылки — абсолютные пути).
- Иконки: GNOME сопоставляет окно far2l с `far2l.desktop` по классу окна (X11) или app_id (Wayland),
  поэтому достаточно переопределить `.desktop` в `~/.local/share/applications` с новым `Icon=`.
- После изменения цветов: `python3 install.py --export theme`, `python3 -m unittest discover -s tests`,
  `python3 tools/e2e.py --screenshots` (при успехе обновит снимки в `environments/*/screenshots/`).
- Снимки в графическом режиме нажимают клавиши через XTEST по коду клавиши: `xdotool key`
  с новыми xkeyboard-config добавляет к F-клавишам Alt, и far2l 2.8 видит Alt+F9 вместо F9.

## Структура репозитория

```
install.py                  установщик: --detect, --verify, --restore, --export
far2l_theme/colors.py       цвета интерфейса и палитра, правила для каждого элемента far2l
theme/graphite.hrd          цвета подсветки синтаксиса в редакторе (фон = BG из colors.py)
far2l_theme/detect.py       каталог настроек, версия far2l, профиль, запущенные процессы
far2l_theme/steps.py        шаги установки и первый запуск far2l в tmux
far2l_theme/backup.py       резервная копия и откат
far2l_theme/verify.py       проверка установки
profiles/far2l-2.6/         far2l 2.6–2.7: тем нет, цвета в settings/farcolors.ini
profiles/far2l-2.8/         far2l 2.8+: пользовательская тема
environments/debian-12-gnome-x11-far2l-2.6/     проверенное окружение + Containerfile + снимки
environments/fedora-44-gnome-wayland-far2l-2.8/ то же
theme/                      farcolors.ini и palette.ini (генерируются из colors.py)
icons/                      иконки far2l и редактора far2l (SVG)
tools/snapshot.py           снимки far2l (Xvfb или tmux) со сводкой цветов
tools/shotcheck.py          проверка цветов на снимках
tools/e2e.py                сквозная проверка во всех окружениях в контейнерах
tests/                      модульные тесты
docs/                       картинки для README
```
